### 🤖 FAQ Chatbot

It's a simple AI based FAQ Chatbot developed with Python, Streamlit, and NLP.
With the help of NLP, the chat bot can respond to queries from a user by referring to the most suitable answer in the FAQ.

## Features:
-Interactive chatbot interface
-Provided answers to commonly asked questions.Responded to common questions.
-Implements NLP text pre-processing
-Uses similarity matching to find the best matching answer
-Simple and easy to use UI.

## Technologies Used:
Python
Streamlit
NLTK
Scikit-learn
NLP (Natural Language Processing)
